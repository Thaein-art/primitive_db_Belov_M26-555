## Управление таблицами

Программа `primitive_db` — консольная база данных,
которая хранит метаданные таблиц в JSON-файле.

### Запуск из исходного кода

Синхронизируйте зависимости:

```bash
uv sync
```

Запустите программу:

```bash
uv run database
```

### Доступные команды

| Команда | Описание |
| --- | --- |
| `create_table <имя> <столбец:тип> ...` | Создаёт таблицу |
| `list_tables` | Показывает список таблиц |
| `drop_table <имя>` | Удаляет таблицу |
| `help` | Показывает справку |
| `exit` | Завершает программу |

Поддерживаемые типы столбцов: `int`, `str`, `bool`, `float`.
Столбец `ID:int` создаётся автоматически и располагается первым.

### Пример использования

```text
Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
```

Метаданные таблиц сохраняются в `db_meta.json`
в текущей рабочей директории.

### Сборка и установка CLI

Соберите пакет:

```bash
uv build
```

Проверьте дистрибутивы:

```bash
uvx twine check dist/*
```

Установите пакет как отдельную CLI-команду:

```bash
uv tool install dist/*.whl
```

После установки запустите программу:

```bash
database
```
